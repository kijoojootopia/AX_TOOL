# 수출 견적서 계산기 — 프롬프트 v2 (현업 기준 보완판)

수출 견적서 계산기 웹페이지를 HTML 파일 하나(index.html)로 만들어줘. 외부 라이브러리 없이 동작(엑셀 읽기만 예외).

## 화면
- 한국어 화면, 견적서 출력물만 영어. 깔끔한 업무용 디자인, 휴대폰에서도 사용 가능(표는 가로 스크롤)

## 입력 1 — 품목표 (행 추가/삭제)
품목명, HS Code(선택), 수량, 단위(pcs/set/carton/kg), 개당 원가(KRW), MOQ(품목별),
협상 단가(USD, 선택 — 바이어 희망가 또는 직접 정한 견적가. 선택한 인코텀즈 기준)

### 품목 일괄 불러오기 (CSV / XLSX)
- "CSV / 엑셀 불러오기" 버튼: 첫 시트의 제목줄을 열 이름(한/영 별칭)으로 자동 매칭해 품목표를 채움
  (품목명·품명·Description / 수량·Qty / 단위·Unit / 개당 원가·원가·Cost / HS Code / MOQ / 협상 단가)
- 필수 열(품목명·수량·개당 원가)이 없으면 오류 문구. 단위 표기 통일(ea→pcs, ctn→carton)
- CSV는 UTF-8과 한글 엑셀 기본 저장 인코딩(CP949) 둘 다 읽기
- XLSX는 SheetJS를 CDN에서 필요할 때만 불러오기(그 외엔 외부 라이브러리 없음)
- "양식 받기 (CSV)" 버튼: 열 이름이 들어간 빈 양식 다운로드(엑셀에서 한글 안 깨지게 BOM 포함)
- 파일은 브라우저 안에서만 읽고 서버로 보내지 않음을 화면에 표시

### HS Code 검색
- 품목별 "검색" 버튼 → 관세청 HS부호(공공데이터포털, HSK 10단위) 기반 data/hsk.json에서 한글·영문 품명/코드 앞자리로 검색
- 맞은 코드와 같은 6단위 소호의 다른 항목('기타' 등)도 함께 표시, 출처·적용 종료일·"참고용 후보" 문구 표시
- 견적서에는 6자리(국제 공통) 또는 입력값 그대로 표기 선택

## 입력 2 — 원가·환율·물류비
- "최신 환율 불러오기" 버튼: 무료·키 없는 API로 USD→KRW 조회
  1순위 https://open.er-api.com/v6/latest/USD (ExchangeRate-API, 하루 1회 갱신)
  실패 시 https://api.frankfurter.dev/v1/latest?base=USD&symbols=KRW (ECB 기준환율)
  → 환율·기준일·출처를 자동 기입, 실패하면 직접 입력 안내
  → "시장 중간값이라 은행 TTB보다 높으니 버퍼를 두라"는 안내 문구
- 목표 마진율(%), 최저 마진율(%)
- 적용 환율(KRW/USD) + 환율 기준일 + 환율 버퍼(%) — 적용환율 = 입력환율 × (1 − 버퍼)
  (안내: 수출대금을 원화로 바꿀 때 기준은 매매기준율이 아니라 전신환매입률(TTB)이거나 회사 사내환율)
- 내륙운송비(KRW), 통관·선적지 부대비용(KRW: 통관수수료·THC·DOC·Wharfage 등)
- 해상운임(USD, 할증료 포함 총액) + 운임 견적 유효기간(날짜)
- 적하보험요율(%)
- 단가 소수점 자릿수(2/3/4), 올림 처리

## 계산 규칙 (명시)
- 마진 = 물품가(EXW) 기준 판매가 대비 이익률: EXW 단가 = 원가(USD) ÷ (1 − 목표마진)
- 물류비는 원가로 전가(마진 미부과), 품목별 배분은 원가금액 비중
- FOB = EXW + (내륙운송 + 통관·선적지 부대비용) / CFR = FOB + 해상운임
- CIF = CFR ÷ (1 − 1.1 × 보험요율)  ← 보험료가 CIF의 110%에 붙는 순환식을 푼 값
- 단가는 지정 자릿수에서 올림, 총액 = 반올림된 단가 × 수량의 합

## 출력 1 — 인코텀즈 비교표
- 품목별 EXW/FOB/CFR/CIF 단가 + 조건별 총액(USD) + 조건별 포함 비용 한 줄 설명
- 조건별 실효 마진율 표시. 협상 단가를 넣으면 그 가격에서 물류비를 역산한 실제 마진 표시
- 최저 마진율 미만이면 빨간색 + 경고 문구
- CFR/CIF 선택 시 견적 유효기간이 운임 유효기간보다 길면 노란 경고

## 출력 2 — 영문 견적서(Quotation) 미리보기
Seller(회사명·주소·연락처), Buyer(회사명·주소), Quotation No.(자동 생성·수정 가능), Date, Valid until(일수 입력 → 날짜 자동),
품목표(No. / Description / HS Code / MOQ / Q'ty / Unit / Unit Price / Amount / Total),
Price Terms: 인코텀즈 + 지정장소(EXW=인도장소, FOB=선적항, CFR·CIF=도착항) + "Incoterms® 2020",
Payment Terms(T/T 30/70, T/T 100% advance, L/C at sight, D/P at sight, 직접 입력), Lead Time, Packing, Origin, Remarks, 서명란

## 기타
- 인쇄 / PDF 저장 버튼(인쇄 시 견적서만)
- 예시 데이터 버튼: 가상 바이어 "ABC Trading Co. (가상)" + 품목 3개, 모든 숫자가 가상임을 화면에 표시
- 접이식 도움말: 4개 조건 비용·위험 이전 시점, 계산식, 컨테이너 화물은 ICC가 FOB 대신 FCA 권장한다는 점, 환율 선택 기준
- 마지막 입력값 브라우저 저장(localStorage, 실패해도 동작)
- 맨 아래 작은 글씨: "참고용 계산 • 실제 견적은 회사 규정과 최신 운임·환율을 확인하세요"
