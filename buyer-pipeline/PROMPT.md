# 바이어 관리 보드 — 프롬프트 v2 (현업 기준 보완판)

해외 바이어 관리 보드 웹페이지를 HTML 파일 하나(index.html)로 만들어줘. 외부 라이브러리 없이 동작.

## 화면
- 한국어 화면, 깔끔한 업무용 디자인. 휴대폰에서는 칸이 세로로 쌓이게

## 칸반 보드
- 6단계: Inquiry / Sample / Quotation / Negotiation / PO / Shipped
- + "Hold / Lost(보류·실주)" 칸: 기본 숨김, 토글로 표시. 합계에서 제외 (실주를 지우지 않고 남겨 재접촉에 활용)
- 데스크톱은 드래그로 이동, 모든 화면에서 카드의 ◀ ▶ 버튼으로도 이동
- 단계를 옮기면 "단계 진입일" 기록 → 카드에 "이 단계 N일째" 표시

## 바이어 카드
회사명(필수), 국가(자동완성), 담당자, 이메일(클릭 시 메일 작성), 관심 품목, 예상 거래액(USD),
마지막 연락일, 다음 연락일, 메모
- 국가별 **현지 시각**과 업무시간(평일 09–18시) 여부 표시 — 전화·메일 타이밍 판단용
- 마지막 연락 후 14일 이상이면 "연락 끊김" 태그

## 팔로업 자동화 (핵심)
- 카드의 "연락함" 버튼: 마지막 연락일 = 오늘, 다음 연락일 = 오늘 + 단계별 기본 간격(영업일 기준, 주말 제외)
  Inquiry 2 / Sample 7 / Quotation 3 / Negotiation 3 / PO 7 / Shipped 10 / Hold·Lost 60 영업일
- 단계를 옮길 때 다음 연락일이 비었거나 지났으면 같은 규칙으로 자동 설정하고 알림 표시

## 오늘 할 일 (맨 위)
- 지난 팔로업(빨강, 오래된 순) / 오늘(주황) / 7일 이내(회색) 세 묶음
- 각 줄에서 바로 "연락함"·"수정"

## 요약
- 단계별 건수·예상 거래액 합계
- 진행 중 합계, **가중 합계(단계별 성사 확률 반영: 10/20/30/50/90%)**, 선적 완료 합계
- 국가 필터, 회사명·담당자·품목 검색

## 데이터
- 카드 추가/수정/삭제(삭제는 확인창)
- CSV 내보내기(엑셀 한글 안 깨지게 BOM) + CSV 불러오기(같은 열 이름, 교체/추가 선택) — 백업·엑셀 이관용
- 브라우저 저장(localStorage, 실패해도 동작) + "브라우저를 바꾸거나 기록을 지우면 사라지니 CSV로 백업" 안내
- "예시 데이터 넣기": 가상 바이어 8곳(미국·베트남·독일·UAE 등), 회사명 뒤 "(가상)", 날짜는 오늘 기준 자동 생성

## 기타
- 단계 뜻·팔로업 간격·가중 합계를 설명하는 접이식 도움말
- 맨 아래 작은 글씨: "연습용 도구 • 실제 고객 정보는 회사 보안 규정에 맞게 관리하세요"
